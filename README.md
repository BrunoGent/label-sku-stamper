# label-sku-stamper

Stamps the SKU(s) from Shopify 4x6 packing slips onto the shipping labels, sorts the labels, and makes a pick list.

- Use it: double-click `run.bat` (newest `shipping*.pdf` in Downloads) or drag a PDF onto it.
- Setup: `py -m pip install -r requirements.txt`
- Full docs live in the Bees and Sonia operating manual: SOP-FUL-001 (how to use) and SOP-TEC-001 (technical).

Customer PDFs and outputs are git-ignored; never commit them.
